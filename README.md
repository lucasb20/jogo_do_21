# jogo_do_21

Jogo do 21, também conhecido como jogo de cartas Blackjack.

Ideia do projeto retirada do livro "O guia essencial de HTML5" de Jeanine Meyer.

Jogo desenvolvido por Lucas Rocha.

Blackjack é um jogo de cartas bem comum como jogo de aposta.

Conceitos básicos:

- É um jogo de jogador vs House.

- Tanto os jogador quanto o House recebem duas cartas no início.

- Todas as cartas do jogador estarão reveladas. Uma carta do House estará revelada e a outra permanecendo virada.

- O jogador deve escolher entre pegar mais uma carta ou manter a quantidade que já tem.

- Cada um terá uma valor na mão com base no valor de suas cartas.

- Se o valor da mão ultrapassar 21, é dado como mão estourada.

- Ganhará quem possuir a maior pontuação na mesa sem estourar.
